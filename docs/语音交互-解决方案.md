# 语音交互 · 可用方案（2026-10-23）

> 结论先放前面：语音今晚"一直用不了"不是识别算法的问题，是**两处环境**把链路掐断了——
> ① 声卡默认设备指错（TTS 没声）② PulseAudio 抢占相机麦克风（ASR VAD 恒为 0）。
> 两个都修好后，`voice_check.sh` 七项全绿、`查询室内温度` 意图 1.00。

---

## 一、链路与四个检查点

```
说话 ──► 讯飞六麦/相机麦 ──► ASR 节点 ──► /voice_words ──► 意图匹配 ──► 对话状态机
                                    ▲                                    │
                                    └──── TTS(/voice/say → tts_net → mpv)┘
```

| 检查点 | 判定 | 失败症状 |
|---|---|---|
| 声卡路由 + 音量 | `amixer -c PCH sget Master` ≥ 70%，`~/.asoundrc` 绑 `CARD=PCH` | 有日志"播放"但**完全没声** |
| TTS 节点 | `pgrep -f tts_net.py`，`/tmp/f_tts.log` 有"播放: …" | 车不说话 |
| ASR 麦克风 | `/tmp/asr.log` 里 `[VAD]` 条数 > 0 | 说了没反应，VAD=0 |
| 置信度/词表 | `appid_params.yaml` 的 `confidence`、`call.bnf` 装载成功 | 识别到但被丢弃 |

## 二、三个真凶（今晚实测）

### 1. TTS 完全没声 —— 默认声卡指错

`~/.asoundrc` 曾写死 `card 0`。USB 枚举一变，`card 0` 变成 Astra 相机（只有采集没有播放），
主板声卡（ALC897）跑到 `card 2`，于是 mpv/aplay 打开默认设备直接失败：

```
couldn't open play stream: No such file or directory
jack server is not running or cannot be started
```

**修法**（按声卡名绑，杜绝卡号漂移）：

```
pcm.!default { type plug; slave.pcm "hw:CARD=PCH,DEV=0" }
ctl.!default { type hw; card PCH }
```

再 `amixer -c PCH sset Master 86% unmute`（现场 70%~86% 都正常）。

### 2. ASR 没麦 —— PulseAudio 抢占

```
[voice_usb] MSPLogin: ret=0(成功)
[voice_usb] QISRBuildGrammar 返回: 0(成功)
[voice_usb] 录音设备: plughw:CARD=S,DEV=0
arecord: main:722: audio open error: Device or resource busy
[VAD] 条数 = 0
```

`fuser -v /dev/snd/*` 显示 `pulseaudio` 占着 `pcmC1D0c`（相机麦克风）。这台车音频全走
ALSA 直连，PulseAudio 没有用处，**起 ASR 前关掉**即可：

```bash
pulseaudio --kill
```

这一条已经写进 `asr_bg.sh`（起 ASR 前自动检查并关闭），以后不用手动敲。

### 3. 识别参数来回调导致"时灵时不灵"

| 参数 | 有效的值 | 说明 |
|---|---|---|
| `confidence`（`vocab/appid_params.yaml`，真正生效的是它）| **5** | 现场正确识别只有 8 分左右，阈值 12 会把真指令整句丢掉（实测过） |
| 麦克风增益 | **60%** | 45% 时真指令只拿 8 分，55% 时 16~20 分，60% 时 30~96 分 |
| 意图匹配阈值 | 0.80 | 低于它的识别结果不执行 |
| 唤醒词 | 第 2 轮起必须 | 收音窗口里再听到"老张同学"回"我在"、**不占轮次** |

## 四、排障决策树

```
车不说话？
├─ /tmp/f_tts.log 有"播放"但没声 → 声卡路由（第三节 1）：amixer 音量 + asoundrc 绑 CARD=PCH
├─ 连"播放"都没有 → tts_net 没跑 / 网络取音频失败 → 重启 tts_net，或临时用 espeak 兜底
└─ 有声音但断断续续 → 音量 <70% 或喇叭线松

说了没反应？
├─ /tmp/asr.log 没有 [VAD] → 麦克风被占：pulseaudio --kill 后 asr_bg.sh
├─ 有 [VAD] 但没 published → confidence 太高（改回 5）或增益过低（改回 60%）
├─ 有 rawtext 但没执行 → 意图匹配 <0.80：说完整指令（"打开卧室灯" 而不是 "开灯"）
└─ 时好时坏 → 环境噪声：临时 export MIC_GAIN=45 再起 ASR，或缩短收音窗口

对话流程问题？
├─ 连喊几声"老张同学"浪费轮次 → 已在 V105 修掉（唤醒词不占轮次）
├─ 喊了唤醒词、紧接的指令没被听见 → 回声门控（ACK 后 0.4 s 清缓冲）；不要贴着车说
└─ 第 5 轮等不到唤醒 → 20 s 窗口，现场要留够时间（可改 WAKE_TIMEOUT）
```

## 五、当前定版参数（V110，识别部分已回到 V100）

```yaml
# _tools/vocab/appid_params.yaml
confidence: 5          # V100 的值
seconds_per_order: 15
appid: 3e41a628

# _tools/asr_bg.sh
MIC_GAIN=60            # 可 export MIC_GAIN=45 临时压噪声
# 起 ASR 前自动 pulseaudio --kill

# _tools/voice_dialog.py
MAX_ROUNDS = 5         # 第 2 轮起必须先喊"老张同学"
NO_REPLY_FIRST = 15    # 第 1 轮
NO_REPLY = 15          # 第 2~5 轮
WAKE_TIMEOUT = 20      # 等唤醒词
```
